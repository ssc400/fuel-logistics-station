# 成品油物流工作空间站（公网版 v2.8）

> 公网部署副本，不含任何密钥。所有用到高德 API 的功能，需使用者各自在浏览器填入自己的高德 KEY。

## 一、运距复核模块（核心可用）

入口：`index.html` → 运距复核页（`dist_verification_v1996.html`）。

1. **首次使用先填 KEY**：页面顶部"高德KEY"框，粘贴你自己的「高德 Web 服务 KEY」。
   - KEY 仅保存在**你本机浏览器**（localStorage，按网址隔离），任何人（含仓库维护者）都看不到。
   - 没填 KEY 就点"开始复核"，会被拦截并提示。
2. **三种核对方式**（默认：最短里程）：
   - 推荐最短（matrix，v3/distance，配额最省，适合全量普查）
   - 最短里程（shortest，v3/direction/driving strategy=2，严格距离优先）
   - 高速优先（highway，v5/direction/driving strategy=34，附过路费）
3. **结果分类筛选**：可按 **地区 / 性质 / 负责人（加油站）** 与 **油库类型（油库）** 组合筛选；导出 Excel 同样带这 4 个分类列。
4. 还支持：仅核对我方自有库、偏差阈值设置、失败根因分析、导出 Excel。

## 二、其他模块

地图、情报等模块依赖高德 JSAPI KEY，公网版未预置，建议在**本地工作站**使用。

## 三、安全说明

- 本仓库**不含任何密钥**。
- 你的 KEY 只存在你自己浏览器的 localStorage，不会上传、不会进仓库。
- 若更换设备/浏览器/清缓存，需重新填入 KEY（历史核对结果存于浏览器 IndexedDB，换网址需重新核对）。

## 四、本地运行（可选）

也可不依赖本公网站，直接用本地 HTTP 服务打开（避免 `file://` 协议拦截外部 API）：

```
cd 本目录
python -m http.server 8765
# 浏览器打开 http://localhost:8765
```
